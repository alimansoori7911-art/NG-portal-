# NGCorion — Design Spec (بازسازی‌شده از اسکرین‌شات)

این پوشه جایگزین فایل فیگما است. همه اندازه‌ها برای **فریم دسکتاپ 1440px** هستند.

## محتوا

```
00-design-tokens.md        رنگ، تایپوگرافی، فاصله‌ها، radius، دکمه‌ها، CSS variables
01-shared-components.md    Header, Breadcrumb, SectionHeader, CTA, Customers, Footer
02-page-terms.md           صفحه قوانین و مقررات
03-page-resources.md       صفحه مرکز منابع
04-page-services.md        صفحه خدمات
wireframes/*.svg           وایرفریم با اندازه واقعی (عدد صورتی = عرض×ارتفاع هر باکس، نوار راست = y و ارتفاع سکشن)
wireframes/preview/*.png   پیش‌نمایش رندرشده وایرفریم‌ها
reference/*.jpg            اسکرین‌شات‌های اصلی کارفرما
assets-placeholder/*.png   تصاویر hero برش‌خورده از اسکرین‌شات (فقط موقت)
```

## نکات مهم

- اندازه‌ها **اندازه‌گیری‌شده و گردشده به گرید 4/8** هستند (خطا ±4 تا ±8px). منبع اصلی عدد، فایل‌های `.md` است؛ SVGها برای چک بصری‌اند.
- اسکرین‌شات‌ها مقیاس یکسان نداشتند (منابع و خدمات/قوانین حدود 12% اختلاف). همه به یک سیستم واحد (container 1312، tokens مشترک) نرمال شده‌اند.
- موارد نامطمئن با `[?]` یا ⚠️ علامت خورده‌اند.
- **باید از کارفرما گرفته شود**: لوگو (SVG)، تصاویر سه‌بعدی hero و CTA، لوگوی مشتریان، نام فونت، متن بخش‌های 07–14 قوانین، طراحی موبایل.

## پرامپت پیشنهادی برای Claude Code

این پوشه را در ریشه پروژه با نام `design-spec/` بگذار و بنویس:

```
در پوشه design-spec/ مشخصات کامل طراحی سه صفحه هست (فریم 1440، RTL، فارسی).
ترتیب خواندن: README.md → 00-design-tokens.md → 01-shared-components.md → فایل صفحه.
برای مقایسه بصری wireframes/preview و reference/ را ببین.

اول فقط tokens و کامپوننت‌های مشترک (Header, Footer, CTA, Customers, SectionHeader) را پلن کن.
اعداد فایل‌های md ملاک هستند، نه برداشت از تصویر.
آیکون‌ها از lucide-react. تصاویر hero از assets-placeholder به‌صورت موقت.
داده‌ها بعداً از JSON بک‌اند می‌آیند؛ محتوای فعلی را در فایل‌های data جدا نگه دار.
```
